# HTML Parquet Viewer v1.0.0

First tagged release of HTML Parquet Viewer, distributed as a self-contained HTML file.

## Included

- Local file opening (picker or drag-and-drop), multiple closable tabs, schema and file metadata inspection, and paginated row previews.
- Japanese and English interface with a compact **JA / EN** header toggle. The choice is retained locally; the initial language follows the browser preference.
- Current-page searching, three-state sorting, and CSV download or copy.
- Parquet v1/v2 and compressed data using uncompressed, Snappy, Gzip, Brotli, Zstandard, and LZ4/LZ4_RAW codecs supported by the bundled parser.
- Accurate display of unannotated binary columns as byte summaries instead of lossy text, plus LZ4_RAW decompression fixes for long matches.
- Offline-capable standalone HTML; file contents are processed in the browser with `connect-src 'none'`.

## Verification

The release candidate passed 84 application regression tests, 8 real-data/decoder tests and 4 Microsoft Edge browser end-to-end tests on the PR branch. Checks cover six compression variants, multi-row-group reads, raw binary and Unicode values, bad inputs, language switching, CSV export and `file://` use.

## Scope and limitations

This is a viewer, not a Parquet query engine. Paging, searching and sorting apply to the current preview page. CSV export and copy include the current page only, not the entire file. For binary values, the viewer displays a byte-length and hex summary (up to the first 24 bytes), not all raw bytes. Certain encodings or unusual files may remain unsupported. Mobile devices, Safari/Firefox and very large files are not exhaustively validated by the release CI.

Download **parquet-viewer.html** from the release assets and open it directly in a modern browser. **SHA256SUMS.txt** provides its checksum. This repository contains the applicable third-party license notices.
